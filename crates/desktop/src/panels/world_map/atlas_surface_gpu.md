# atlas_surface_gpu.rs

## Purpose
Render measured height-field geometry into private color/depth targets, then
composite it into egui. Foreground terrain occludes farther triangles naturally.

## Contracts
Height R32Float and pigment RGBA textures upload together in bounded row stripes
(8 MiB per callback). Only complete images replace the active source; previous
georeferenced terrain survives staging. Replaced source IDs are retired, but
each mode keeps its last uploaded sources and render target when hidden. An
explicit invalidation generation clears both modes, including while Atlas is
hidden; normal Globe/Local/theme switches never discard those resources.
Triangles are generated by vertex/instance indices and heights are bilinearly
sampled in the vertex shader. No CPU view-dependent mesh build is required.
Stationary camera/source/style combinations reuse the completed color/depth image.
Local depth uses the same monotonic ground-distance rule as native contour
occlusion. Globe uses perspective distance to the actual displaced sphere.

The surface shader is composed with runtime measured-height lighting. Light/style uniforms participate in the cached render key, so moving light redraws the retained height field without source reads or re-upload.

Forest coverage binds at source slot 3 and shares the staging budget through `atlas_surface_forest`. Readiness and mask ID participate in render caching; visibility changes restore the original material without source re-upload.
