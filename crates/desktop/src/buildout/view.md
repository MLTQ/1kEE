# view.rs

The Layers drawer controls the saved opt-in and opens a searchable browser
with Campuses, Rules and News tabs. Detail pages use publisher-supplied project
stages, MW, position precision, confidence, jurisdiction, dates and citations.
News links to related records by source ID.

The drawer shows the time of the last successful check and the stage and position-precision legend. Clicking an Earth marker selects the corresponding record in the browser.
Rules without a point remain searchable by jurisdiction. Selection is stored
by ID so a reordered snapshot cannot select a different record.
