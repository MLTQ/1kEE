Opens one source-bound SQLite LOD sidecar per administrative level. Its versioned
name, file length, mtime and inode identify compatible geometry. Builds use a
private temporary file and atomic publication. A read-only source folder can use
a reusable, source-keyed sidecar in the temporary folder. Queries use ring or piece bounding boxes, including
wrapped longitudes. Outlines load only visible 256-edge chunks; shading rejoins
complete rings and respects incomplete relation flags. Original detail reads
source offsets from the same opened file used to validate the sidecar.
