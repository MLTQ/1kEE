# admin_resume.rs

Interrupts the real shared importer immediately after the first country publication.
The public binary reader must already see its complete outer ring, hole and island
while finer levels are empty and coverage is marked partial. Resume must skip the
saved country, preserve its exact output, and complete the other levels. Removing
an output file then resuming must republish it without any geometry assembly.
All mutation stays in an owned temporary directory with the committed tiny PBF.
