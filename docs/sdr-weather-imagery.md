# Satellite imagery on the 1kEE globe

## Global satellite weather

On **Earth**, open **Layers → Global Satellite Weather**. Select either layer, or turn on both and adjust their opacity to follow clouds over the true-color image. Both layers work in Globe and Local. Your choices persist across restarts.

- **Daily true color** uses NASA GIBS corrected reflectance from NOAA-20 VIIRS. 1kEE requests the most recent available date through yesterday UTC. A day's mosaic combines many passes taken at different times. Polar night and missing observations can appear black. The global image is 4096 × 2048 pixels. [NASA Worldview](https://worldview.earthdata.nasa.gov/?l=VIIRS_NOAA20_CorrectedReflectance_TrueColor) · [GIBS access and time dimensions](https://nasa-gibs.github.io/gibs-api-docs/access-basics/)
- **Three-hourly infrared** uses EUMETSAT's 10.8 µm geostationary ring mosaic. It shows cloud and surface emission by day and night. The most recent published frame may lag the current three-hour interval. At high latitudes the view is oblique, and areas beyond coverage are transparent. The global image is 2048 × 1024 pixels. [EUMETSAT infrared product](https://view.eumetsat.int/productviewer/productDetails/mumi%3Aworldcloudmap_ir108)

The time below each checkbox identifies the displayed image in UTC. While enabled on Earth, 1kEE checks published dates hourly for true color and every 15 minutes for infrared. **Check now** checks the provider immediately. If a request fails, the current image stays visible with its original date and 1kEE retries in five minutes. The last good PNG for each source is cached in `satellite/global-weather.sqlite` within the selected Data folder. These are online layers and require no radio, account, or GDAL installation.

## Receive your own Meteor pass

Use SatDump to receive a Meteor-M N2-3 or N2-4 **LRPT** downlink and project the decoded image. Import the resulting GeoTIFF in the 1kEE desktop app. Each pass gives you a swath of clouds and surface features along the satellite’s track. NOAA retired the NOAA-15, -18 and -19 satellites in 2025, so their older analog APT tutorials no longer yield live images. [Meteor reception guide](https://a-centauri.com/articoli/meteor-satellite-reception) · [NOAA mission closure](https://www.nesdis.noaa.gov/news/legacy-orbit-noaa-decommissions-the-poes-satellite-constellation)

## Set up the station

1. Start with the RTL-SDR. Connect an outdoor 137 MHz antenna with a clear view of the sky. A simple horizontal V-dipole uses two elements about 53.4 cm long, with 120° between them. A short magnetic-base whip can be tried upright on a steel ground plane. Leave antenna power (bias tee) off for a passive antenna. A 137 MHz filtered low-noise amplifier near the feed can help at a noisy site. [V-dipole dimensions and orientation](https://w4hhh.org/wp-content/uploads/2022/09/DIY-137MHz-WX-sat-V-dipole-antenna.pdf) · [Reception and amplifier setup](https://a-centauri.com/articoli/meteor-satellite-reception)
2. Install SatDump with support for your radio. On Arch Linux the AUR package is `satdump` (`yay -S satdump` with yay). The `rtl-sdr` and `hackrf` packages supply device tools. With the receiver plugged in, run `rtl_test -s 1024000` for the RTL-SDR or `hackrf_info` for the HackRF. Stop the RTL test with Ctrl+C before opening the radio in SatDump. Install the `gdal` package on the computer running 1kEE. [SatDump installation and releases](https://github.com/SatDump/SatDump) · [Arch SatDump package](https://aur.archlinux.org/packages/satdump) · [Arch RTL-SDR driver](https://archlinux.org/packages/extra/x86_64/rtl-sdr/)
3. In SatDump set the receiving station latitude, longitude and altitude, sync the computer clock, and refresh the orbital elements (TLEs). In Tracking, select **METEOR-M2 3** (NORAD 57166) or **METEOR-M2 4** (59051). Choose a pass with a high maximum elevation, ideally over 50° for a first attempt. The time and open sky in the direction of the pass both matter. [SatDump tracking](https://docs.satdump.org/md_docs_2pages_2QuickStart.html) · [CelesTrak weather satellite elements](https://celestrak.org/NORAD/elements/gp.php?GROUP=weather&FORMAT=tle)
4. Select the **METEOR M2-x LRPT 72k** processing pipeline. Start with **137.900 MHz** and check recent observations before the pass. The alternate downlink is **137.100 MHz**, and SatDump also has an 80k decoder for transmissions in that mode. For the RTL-SDR use **1.024 MS/s** with manual tuner gain, then adjust for the best signal-to-noise ratio. For the HackRF One use receive mode at **8 MS/s**, initially with the RF amp off and IF and baseband gains at 16 dB each. Both radios can receive Meteor independently. [Meteor settings](https://a-centauri.com/articoli/meteor-satellite-reception) · [SatNOGS N2-4 transmitters and observations](https://db.satnogs.org/satellite/59051/) · [HackRF sample rate](https://hackrf.readthedocs.io/en/stable/sampling_rate.html) · [HackRF gain controls](https://hackrf.readthedocs.io/en/latest/setting_gain.html)
5. Start the receiver and live processing a minute or two before the predicted rise. Enable DC blocking in the Meteor pipeline. Look for the signal on the waterfall, Viterbi lock and good Reed–Solomon frames. After the satellite sets, stop processing, stop the receiver, and let SatDump finish creating the products. Retain the pass directory with its acquisition time and decoded data. If you record for offline decoding, save **baseband I/Q** and its sample format, rate, center frequency and UTC start time. [SatDump Meteor decoding walkthrough](https://a-centauri.com/articoli/meteor-satellite-reception)

## Project and import the pass

1. Open the decoded MSU-MR product in SatDump. Choose a daylight composite or an available infrared channel for a night pass. Add the image to a projection and choose **Equirectangular** with automatic bounds/scale. Disable drawn borders, labels and any background map, and preserve transparency outside the swath where available. Save the **projection** as TIFF. Include the satellite, UTC acquisition time and product in the filename, for example `Meteor-M2-4_2026-11-09T1910Z_MSU-MR.tif`. Accurate pass times and orbital elements are needed to geolocate the scan lines. [SatDump projection settings](https://docs.satdump.org/md_docs_2pages_2Projections.html) · [SatDump Meteor geolocation](https://github.com/SatDump/SatDump/blob/master/plugins/meteor_support/meteor/instruments/msumr/module_meteor_msumr_lrpt.cpp)
2. Check the file with `gdalinfo pass.tif`. Look for the coordinate system, origin, pixel size, and corner coordinates that fit the pass. Use a display-ready 8- or 16-bit grayscale/RGB image with optional alpha. A raw scan or screenshot needs projection in SatDump first.
3. Run the current 1kEE desktop build, select **Earth → Layers → Import Layer…**, and pick the TIFF. Click **Center** beside the filename. Toggle the image or reduce its opacity and check the coastline against features in the pass. The same layer displays in Globe and Local views. In Settings → Files & Cache you can select the directory containing `gdalinfo` and `gdalwarp` if they are outside your PATH.

You can import multiple passes. 1kEE scales the preview to at most 4096 pixels on the longest side, subject to the GPU texture limit. The source file holds the full resolution. Imported layers are session-only and can be reopened from disk. Keeping the acquisition time in the filename distinguishes observations when comparing passes. SatDump can schedule future receptions through its satellite tracking controls. Each finished GeoTIFF is imported manually.

## Continuous coverage from GOES

Within the GOES-East footprint, GOES-19 broadcasts HRIT/EMWIN continuously at **1694.1 MHz**. GOES-18 serves the western footprint. A fixed station needs a clear line of sight, a dish around 1 m or larger depending on elevation, an appropriately polarized L-band feed, and a filtered L-band low-noise amplifier at the feed. Use SatDump’s GOES HRIT decoder, export a projected display product, and import it the same way. NOAA lists the rebroadcast imagery, channel schedule, and antenna sizing by elevation. [NOAA HRIT/EMWIN specifications](https://ospo.noaa.gov/operations/goes/hrit/index.html)
