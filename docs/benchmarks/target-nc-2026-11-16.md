# Target: Kinston, North Carolina

Live validation on 2026-11-16, centered at 35.26° N, 77.58° W with a WGS84
radius of 1,000 m. GPU: NVIDIA RTX 4090, Vulkan, driver 615.78.08.

| Display | Geometry | Geometry bytes | Synchronized frame time |
|---|---:|---:|---:|
| Original point cloud | 8,000,000 returns | 160,000,000 | 5.22 ms |
| DEM display mesh | 263,169 vertices / 1,572,864 triangle indices | 11,554,836 | 0.14 ms |

Timings average 30 iterations of CPU preparation, GPU submission and an explicit
GPU wait at 1280 × 720. They exclude the surrounding application UI and do not
predict interactive frame rate on other devices. Context loaded 3,465 draped
segments; it was excluded from these isolated rendering timings. Texture,
driver, staging and CPU allocations are excluded from geometry byte counts.

The cloud reached the default eight-million-point budget and is explicitly
**incomplete**. The user can request up to sixteen million points. Its source
was `NC_HurricaneFlorence_3_2020`, acquisition dates 2019-12-08 through
2020-01-26. Original source Z spans 4.61–61.51. The EPT metadata omits vertical
reference and Z units; no quantitative comparison or automatic vertical
alignment with the state's DEM is claimed. Source classes include 5,523,993
unclassified returns, 2,464,701 ground returns, 6,513 water returns and 4,793
class-20 returns. Unclassified points are never relabelled as trees/buildings.

Loading took 13.98 s with EPT blocks already cached and a fresh DEM request.
The DEM request retained a roughly one-metre numeric grid; its display mesh
uses approximately 3.9 m sampling. Different source dates, classification,
sampling and metadata mean these renderings are not independent accuracy
benchmarks against surveyed ground control.

Checks cover exact original XYZ retention on a LAS fixture, geodesic radial
clipping at NC/equator/polar/date-line locations, local GPU-coordinate error
below 0.1 mm on the fixture, point classes, depth ordering, camera movement,
sRGB compositing, cancellation and GPU buffer release. Headless egui input
tests exercise Local-only tool visibility, radial selection, click entry,
free flight and Escape with unchanged Local camera state.

Native unit/CLI checks and strict Clippy pass with builder and EPT features
enabled. Desktop Clippy passes with the existing `approx_constant` lint
excluded; unrelated camera/generated-star diagnostics remain tracked in
`1kee-e5z`. Target/LiDAR/settings regressions and the release build pass.
